# Netflix Clone 🎬



A **Full-Stack Netflix Clone** replicating the core functionality of Netflix, built with **React.js** for the frontend and **Node.js + Express.js + MongoDB** for the backend. Users can sign up, log in, browse movies, search for titles, and experience a smooth, responsive interface with dynamic content.

---

## 🚀 Features

- **User Authentication:** Signup, login, and secure password management.  
- **Dynamic Movie Listings:** Browse popular and trending movies fetched dynamically.  
- **Search Functionality:** Search for your favorite movies with real-time results.  
- **Responsive UI:** Works seamlessly across desktop, tablet, and mobile devices.  
- **Interactive Components:** Smooth UI transitions, sliders, and modals.  
- **Full-Stack Architecture:** React.js frontend with Node.js & Express.js backend and MongoDB database.
